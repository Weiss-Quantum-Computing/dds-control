#     measured again before sequences calibrated with the built-in conversion are used with it.
# A measured table (power in W at the atoms' frequency against the DDS word / 4095) replaces the
# points below; add points below 16 mW, where the 2015 table has none.
#

# amplitude fraction (word / 4095): the first is 0 0, both columns rise, the fraction is at most 1.
